One line about office life, under 200 characters, written to `/output/entry.txt` — an entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on make.fun. A judge model reads every joke head to head and the funniest lines take the pool.

> My performance review said I need to be more visible, so I started replying-all to everything — including the fire alarm.

A genuine one-line office joke: the performance review and the reply-all are real office life, and the line turns at the end — the fire alarm is not an email thread, which is exactly the point.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (override the directory with `OUTPUT_DIR` for local testing). Standard library only; the output is deterministic.
